01WEEK

CLI / HTTP · curl.js

模仿 curl 的 HTTP 命令列用戶端

Node.jsMVPHTTP / HTTPS零依賴
本機資料夾 ↗

以 Node.js 內建 http / https 模組實作的 curl 模擬器。入口只負責接線，Presenter 解析參數與流程，View 管理輸出，Model 處理網路傳輸；所有角色單向依賴，可各自替換與測試。

支援功能

  • 方法與資料：-X 指定方法、-d 可重複並以 & 串接，有資料時自動推斷 POST。
  • 標頭與認證：-H 自訂標頭、-u 轉為 Basic Base64 授權。
  • 輸出控制：-o 存檔、-i 含標頭、-I 只取標頭、-f 網路錯誤狀態。
  • 重新導向：-L 自動跟隨 301/302/303/307/308，最多 50 次，以 new URL(location, base) 解析相對路徑。
  • 診訊分流：主體寫 stdout；-v 與錯誤寫 stderr，可用 2>/dev/null 過濾。
  • 逾時：--connect-timeout / --max-time，預設 30 秒。

架構與資料流

curl.js ─▶ Presenter ─▶ Model ─▶ node:http / https
                │
                └──────▶ View ─▶ stdout / stderr / fs

parseArgs → buildRequest(spec) → model.fetch(spec)
          → -f / -i / -o / writeBody → exitCode 0|1|2

退出碼：0 成功、1 語法或連線錯誤、2 未提供 URL。

檔案地圖

01/
├── curl.js          入口：呼叫 Presenter
├── srv/srv.js       本地測試伺服器 :8123
└── src/
    ├── presenter.js 參數解析 / 流程 / exit code
    ├── view.js      所有輸出與寫檔
    └── model.js     HTTP 傳輸 / 導向 / 逾時

執行與驗證

node curl.js https://example.com
node curl.js -o page.html -L https://example.com
node curl.js -d "name=test" -H "Accept: application/json" https://httpbin.org/post
node srv/srv.js
node curl.js -L -u user:pass http://127.0.0.1:8123/redirect

測試伺服器提供 /auth、/redirect、/echo 三個情境，其餘路徑回傳 hello。

Web / API · 大學校務系統

三角色校務行政資訊入口

Node.jsSPAJSON DBSHA-256 + salt
本機資料夾 ↗

涵蓋教務處、教師、學生三種角色的校務系統：登入與權限、系所／學生／教師／課程 CRUD、線上選課、成績登錄與成績單。後端以 MVP 分層，前端為原生 JavaScript 單頁應用。

角色功能

功能教務處教師學生
課程清單✔✔✔
系所 / 學生 / 教師 / 課程管理✔——
開課與修課名單、成績登錄—✔—
加選 / 退選、成績單與 GPA——✔

示範帳號：admin / T001 / S001，密碼皆為 1111；雜湊存放，Token 由 crypto.randomBytes 產生。

業務規則

  1. 加選檢查順序：課程存在 → 未重複 → 未額滿 → 不與已選時段衝堂；任一失敗回 409 並說明原因。
  2. 排課格式：["1-1","1-2"] 代表星期一第 1、2 節，作為重疊比對依據。
  3. 成績：教師僅能登錄自己的課程（403），分數限 0–100，回傳 A+ / A / … / F 等第。
  4. 權限：API 標註 public / any / admin / teacher / student；未登入 401、角色不符 403。

前端與測試

  • Hash 路由切換角色選單；通用「表格 + 表單彈窗」CRUD 元件。
  • 課程表即時標示已選／可選／滿班／衝堂；成績單含等第、學分、加權平均與 4.0 GPA。
  • 所有渲染資料經 esc() 跳脫，防 XSS。

05WEEK

Container · Docker Microservice

三層式容器微服務系統

Docker ComposeNginxNode.jsPostgreSQL
本機資料夾 ↗

以 Docker Compose 編排 Nginx、Express API 與 PostgreSQL 三個容器；兩層網路隔離、健康檢查控制啟動順序、Named Volume 保存資料，並以多階段建置與非 root 執行強化安全性。

服務與網路

服務映像對外職責
webnginx:1.27-alpine8080 → 80靜態頁 + /api 反向代理
backend./backend build無Express API，連線 db:5432
dbpostgres:16-alpine無資料持久化於 pgdata

frontend 網路連 web / backend；backend 網路為 internal，db 僅掛載於此，外部無法直接連線。

請求路徑

瀏覽器 :8080
   │
   ▼  web (Nginx)
   │  /api/* → proxy_pass http://backend:3000
   ▼  backend (Express)
   │  pg(host: db, port: 5432)
   ▼  db (PostgreSQL + pgdata)

API：GET /api/health（Liveness）、GET /api/status（Readiness，查 DB）、GET /healthz（Nginx）。

設計重點

  • depends_on: condition: service_healthy 等待 db / backend 就緒，避免連線競態。
  • npm ci + lockfile 可重現建置；最終映像以內建 node 使用者執行。
  • 監聽 SIGTERM / SIGINT，先停止收要求、關閉連線池再結束。
  • Nginx 傳遞 Host、X-Real-IP、X-Forwarded-*；啟用 Gzip 與日誌輪替。
  • pg.Pool 設連線與閒置逾時，避免連線耗盡。

執行與疑難排解

cp .env.example .env
docker compose up -d --build
docker compose ps
curl http://localhost:8080/api/status
docker compose logs -f backend
docker compose down -v

連接埠衝突可改 WEB_PORT；PostgreSQL 版本不相容時需清除舊 pgdata 或執行 pg_dump / pg_upgrade。

Domain project · ALU-CHECK

鋁業 CAD 精密比對系統

PythonDXFOpenCVStreamlit
本機資料夾 ↗

針對鋁擠型、散熱片、板金與機構件，將 DXF 圖面量測與客戶規格逐項比對：尺寸公差、標註文字是否被覆寫，以及以 OpenCV 疊圖找出孔位偏移與輪廓變形。圖面與規格以本機運算為主。

核心能力

  • DXF 解析：DIMENSION / CIRCLE / ARC / LINE，mm / cm / m / inch 換算，SHA-256 + pickle 快取。
  • 規格匯入：CSV、TSV、XLSX、JSON、PDF、TXT、Markdown；中英文欄名別名對應。
  • 加權配對：名稱／別名、尺寸類型、數值、CAD Handle；全域貪婪確保一個量測只用一次。
  • 公差判定：±0.05、+0.10/-0.05、上下限與範圍。
  • 文字竄改檢查：幾何 3.80 mm 但文字覆寫為 T=4.00 時標記需人工複核。
  • 視覺比對：移除標註後正規化線稿，比較形狀、面積、質心與重疊率，輸出差異疊圖。

資料流與模組

DXF ─▶ cad_parser ─▶ CADDocument ─┐
                                    ├─▶ matcher.compare_specs ─▶ MatchResult[]
規格 ─▶ specs.load_specs ─▶ SpecItem[]┘          │
                                        ├─▶ render ─▶ 標註圖
                                        ├─▶ report ─▶ HTML/CSV/JSON
                                        └─▶ vision.compare_images ◀─ 參考圖

判定狀態：pass / fail / missing / warning / invalid / error；文字異常保守列為 warning，不直接推斷惡意竄改。

示範與批次指令

streamlit run app.py
python scripts\make_demo.py
python scripts\batch_check.py examples --spec examples\demo_specs.csv --out reports --html
python -m pytest -q

示範含 demo_actual.dxf、demo_ideal.dxf、demo_specs.csv 與 demo_reference.png；批次輸出每張圖的 CSV / JSON / HTML 與 batch_summary.csv。

  • 快捷鍵：N 新增、/ 搜尋、Cmd/Ctrl + Enter 儲存、Esc 關閉。
  • 響應式版面、載入骨架、錯誤重試、Toast；骨架與紙張傾角由自訂 CSS 完成。
  • 字型 Fraunces / Newsreader / JetBrains Mono 以 Fontsource 自我託管。

本週作業是撰寫一個套件，並公開發布到公開套件登錄 npm，讓任何人都能以 npm install digital-conversion 安裝使用。套件收錄六個字串與數字工具函式，未壓縮約 4.4 kB、無執行期依賴；同時支援 CommonJS 與 ES Modules，並以 Node.js 內建 test runner 做完整參數驗證。Cloudflare 的部署成果屬於第 9 週 Field Notes，與本週的 npm 公開套件不同。

API

函式說明範例
reverseStringUnicode 安全反轉'你好' → '好你'
isPalindrome忽略大小寫、空白、標點'A man, a plan…' → true
capitalizeWords字首大寫、其餘小寫，保留空白'hello world' → 'Hello World'
formatThousands千分位，含負數與小數1234567 → '1,234,567'
randomInt含頭尾隨機整數randomInt(1,6)
clamp限制在最小值與最大值之間clamp(42,0,10) → 10

使用與錯誤處理

npm install digital-conversion
const { reverseString, clamp } = require('digital-conversion');
import { formatThousands } from 'digital-conversion';

formatThousands('1000');  // TypeError
randomInt(10, 1);         // RangeError
npm test

需求 Node.js 18+；遵循 Semantic Versioning，授權為 ISC。

公開發布紀錄

  • 公開位置：npm 套件登錄，套件名稱 digital-conversion；任何人皆可公開安裝。
  • 版本與授權：1.0.0，ISC 授權；版本變動依 Semantic Versioning 區分 patch / minor / major。
  • 套件內容：package.json 的 files 只打包 index.js、README.md 與 LICENSE，保持體積精簡。
  • 品質確認：npm test 使用 Node.js 內建 test runner 驗證六個函式與參數錯誤處理。
  • 與其他週的界線：Cloudflare Workers + D1 的線上服務在第 9 週；本週的重點是「寫套件並公開發布到 npm」。
