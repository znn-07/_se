📚 Docker 與微服務核心知識

1. Nginx 網頁與反向代理

擔任前端靜態網頁伺服器，並透過 Reverse Proxy 將 /api 請求安全轉發至後端容器，解決跨域並隱藏埠口。

2. Node.js 開發環境

使用 Express 框架建立 API 伺服器，透過 pg 套件連接資料庫，處理商業邏輯與 JSON 資料交換。

3. PostgreSQL 資料庫

提供關聯式資料儲存，並結合 Docker Named Volume 達成資料持久化，確保容器重啟後資料不遺失。

4. 容器健康檢查

透過 Docker healthcheck 與 depends_on 條件，確保後端在資料庫就緒後才啟動。
